# WeCode-e-Dragoes
Jogo de exploração em grade (estilo RPG) com renderização de mapa a partir de matriz, sistema de movimentação por teclado, combate por colisão contra múltiplos inimigos gerados aleatoriamente, e itens bônus (cura e melhoria de ataque) espalhados pelo cenário. Implementação de atributos de personagem (vida e ataque).
